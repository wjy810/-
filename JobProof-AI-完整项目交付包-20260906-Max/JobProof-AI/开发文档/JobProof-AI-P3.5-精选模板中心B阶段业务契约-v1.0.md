## 1. 业务逻辑确认记录

### 1.1 已确认方向

采用 **B：精选结构化模板中心**。首批冻结 12 个版式家族；每个家族以稳定 ID 标识，颜色、是否显示照片、页数等由变体承载，不复制业务内容和渲染逻辑。C 阶段智能推荐/ATS 评分/多模板比较/AI 精简，A+ 阶段海量资产分层均不进入本期。

### 1.2 已确认不变量

1. 内容事实只来自画像、证据与用户确认；HICV 示例姓名、公司、项目、奖项和数字不得写入用户简历。
2. 简历内容版本与版式实例分离。换版只改变模板版本/主题变体绑定，不重写、不删除、不静默裁剪内容。
3. 内容溢出必须定位到页码和槽位，阻止冻结及导出；本期不自动调用 AI 删除、压缩或虚构内容。
4. 已发布模板版本不可原地修改；下架不破坏历史冻结版本及投递快照。
5. 生产目录只展示已发布且通过全部生产门禁的模板版本；候选、测试、驳回、退休版本不进入普通用户新建/换版流程。
6. 现有 `ResumeTemplateCode`（软件开发、测试、数据分析、产品）**只是内容初始化策略**；它不等于、不派生、不复用本文件的版式模板 ID。一个内容初始化策略可以绑定任意兼容的已发布版式。
7. PDF 保留现有主链路；DOCX 不得仅复制 HICV 原始文件，必须由受控文档模型和版式定义生成并记录版本快照。
8. ATS 等级在本清单中是**候选设计等级**，不是已经实测的解析成功率或评分；生产发布前须用文本提取顺序和代表性 ATS 测试重新定级。

### 1.3 授权边界

HICV `LICENSE` 仅明确：在保留 HICV.cn 署名/来源信息的条件下，可复制、分享、改编并用于简历撰写、教育、求职和非商业模板分发。**这不等于 JobProof 已取得商业产品生产使用许可。**

因此首批 12 个 HICV 条目都只是“来源候选/视觉与结构参考”，不得因进入清单而发布到商业产品。任何基于 HICV 资产的生产版本须先完成商业授权书面确认，记录授权主体、范围、地域、期限、可改编/在线生成/再分发权限、署名方式和证据引用；确认前状态不得超过 `REVIEWING`，也可改为仅参考后由 JobProof 独立设计、并完成相似性与权利复核。

## 7. 状态流转

### 7.1 候选资产

`DISCOVERED → REVIEWING → APPROVED | REJECTED`

- 商业授权未确认、文件安全不合格、来源不明、宏/外链/不可控嵌入、兼容测试失败：不得 `APPROVED`。
- 驳回保留原因与指纹；再次导入相同文件不得绕过既有结论。

### 7.2 模板版本

`DRAFT → TESTING → PUBLISHED → RETIRED`

- `TESTING` 失败返回 `DRAFT` 形成新修订记录；已 `PUBLISHED` 不回到草稿。
- `RETIRED` 后禁止新建/换版，历史冻结实例继续按快照渲染。

### 7.3 版式实例

`DRAFT → VALID | OVERFLOW → FROZEN → ARCHIVED`

- 内容或模板变化须重新计算，`OVERFLOW` 修复后才可回 `VALID`。
- `FROZEN` 不可原地修改；修改内容或换版产生新实例/版本。

### 7.4 渲染产物

`QUEUED → PROCESSING → SUCCEEDED | FAILED`

- 重试必须创建可追踪的新尝试或幂等返回原任务；不得覆盖成功产物审计快照。
- 格式未开放、实例未冻结或存在溢出时不得进入队列。

## 9. 异常与边界场景

| 场景 | 系统行为 | 用户/管理员反馈 | 禁止行为 |
| --- | --- | --- | --- |
| 商业授权未确认 | 候选停留 `REVIEWING` 或仅作参考 | 明示“商业生产授权未确认” | 宣称已获商业许可或发布 |
| DOCX 损坏/含宏/外链/危险嵌入 | 拒绝导入并留安全记录 | 显示具体类别，不暴露敏感路径 | 直接交给渲染器 |
| 字体缺失 | 使用已声明回退并重新测分页；无稳定回退则测试失败 | 显示字体与分页警告 | 静默替换并称一致 |
| 浮动对象错位 | 测试失败或改为独立受控版式 | 定位对象/页面 | 忽略后发布 |
| Word/WPS 结果不一致 | 降级格式、退回草稿或淘汰候选 | 显示未通过的编辑器/版本 | 以 README 声明代替实测 |
| ATS 顺序异常 | 降低候选等级或拒绝生产发布 | 明示风险与实测依据 | 宣称 ATS 友好 |
| 内容溢出 | 标记 `OVERFLOW`，定位页码/槽位，阻止冻结/导出 | 给出可由用户执行的内容/模板选择 | 自动删除、压缩、裁剪事实 |
| 模板已退休 | 禁止新选；历史快照可读/可重渲染 | 显示历史模板已退休 | 把历史实例强制迁移到新版 |
| 版本并发冲突 | 拒绝过期写入，保留输入 | 提示刷新并重新应用 | 静默覆盖 |
| 渲染失败/超时 | 记录失败阶段和版本，不生成成功产物 | 显示可理解原因；是否重试按任务契约 | 返回空文件或伪成功 |
| HICV 示例内容出现 | 在映射/测试阶段拒绝进入用户模型 | 标记污染来源 | 当作默认占位数据保存 |
| 旧 `ResumeTemplateCode` 请求 | 仅执行对应内容初始化，再显式选择/默认绑定合法版式 | 保持旧请求兼容 | 将其值写入新版式家族 ID |

## 10. 验收与发布门禁

### 10.1 契约验收

1. 12 个稳定 ID 唯一、不可复用；展示名、家族、变体、语言、页数、ATS 候选等级、照片和 HICV 候选齐全。
2. `ResumeTemplateCode` 与新版式 ID 分离，换版不改变内容事实。
3. CRUD、页面操作、权限、状态、模块交互、异常与本节验收能相互追溯，无未声明假设。
4. 所有未实测项显式标记“未验证”，实现与 UI 不得提前展示为通过。

### 10.2 单模板生产发布门禁

每个版本必须同时满足：来源与权利证据完整；若使用/改编 HICV 资产则商业授权书面确认且署名方案落实；安全扫描通过；短/中/长三档内容渲染；空区块、超长公司名、多项目、中英文混排和无照片场景通过；溢出定位确定；真实文本与阅读顺序通过；字体及回退通过；浮动对象审查通过；预览/PDF 对照通过；目标 Word/WPS 兼容通过；ATS 等级经实测确认；审计记录完整。任一失败不得 `PUBLISHED`。

### 10.3 DOCX 开放门禁

DOCX 仅在至少 3 个代表家族（ATS 极简单栏、技术双页、中文标准表格）完成 Word 与 WPS 的打开/保存/重开、字体回退、浮动对象、分页、文本顺序、预览/PDF 对照测试后，按已通过模板逐个开放。未测试家族保持 DOCX 格式禁用；PDF 可用性也须独立验证，不因旧链路存在而自动判定通过。

### 10.4 端到端验收

普通用户只能浏览生产模板；可用本人真实内容预览；创建/换版不改变内容；溢出明确阻断；冻结同时快照内容与模板版本；退休后历史投递不变；无权限用户无法操作他人简历；管理员无法以后台权限读取用户原文；授权不清、兼容未过或 ATS 未实测的模板无法发布。

## 11. 禁止假设项与后续变更

- 不假设 HICV 已许可商业在线简历生成、商业再分发或产品内打包。
- 不假设索引中存在即代表文件可打开、无宏/外链、字体可用、预览正确或 Word/WPS 一致。
- 不假设“高 ATS”已通过任何第三方 ATS；发布前必须实测。
- 不假设照片为必填；不采集或推断年龄、性别等敏感属性来决定模板。
- 不假设 DOCX 与 PDF 同步开放；按格式、模板版本分别记录能力。
- 不实现智能推荐、AI 精简、多模板比较、用户上传、海量实验库、付费模板或拖拽设计器。

冻结后若修改家族 ID、权限、状态、授权结论、发布门禁、换版语义或导出范围，必须先升级本契约版本，再评估数据库、后端、前端、历史快照和测试影响；不得在实现中自行补规则。

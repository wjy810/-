# 16 套模板视觉复审与修订

日期：2026-10-21。修订：新增模板 revision 2。

## 复审结论

第一版的视觉验收不充分。星图的松散折线缺少完整构图，若干模板依赖相似的页头、浅色满高侧栏和角落贴图来区分，装饰与正文的关系没有处理好。用户截图还暴露出可读性缺陷：应用深色主题将姓名、公司／项目标题染成了近白色。第一轮独立打印页的验证没有覆盖这个应用外壳样式污染问题。

本次把可读性缺陷与版式问题分别处理。16 套均复查，保留可用的结构，重排问题较明显的页头与装饰；未更改模板 ID、简历字段、已有正文或用户保存的设计选择。

## 可读性修复

应用全局 `h1`–`h6` 使用 `--text-primary`，深色模式下为近白色。简历纸面的姓名及条目标题原先依赖继承，因而被全局标题颜色覆盖。现在简历根节点明确隔离标题颜色、字体和字距，纸面使用独立浅色渲染环境。新模板姓名和条目标题也有明确的纸面颜色；星图深色页头使用对应的反白文字令牌。

新增 `frontend/scripts/template-theme-acceptance.mjs`，在登录后的实际详情页逐套切换应用深浅主题，等待字体加载及分页稳定，比较姓名／条目标题颜色和页数，并检查标题对比度。该检查不再只依赖 `print.html`。

复核还发现首次加载的分页测量存在时序问题：字体就绪或自动紧凑样式切换后，浏览器尚未完成下一帧布局就开始测量，偶尔将实际能放进一页的内容分成两页。现已在字体就绪、每轮紧凑样式更新后等待一帧，再读取区域尺寸；最终 64 个实际详情页场景已验证深浅主题页数一致且正文未越出分区。

## 1. 设计目标

1. **一眼就专业**：任何模板在填入真实内容后，都应达到专业设计师交付的水准——层级清楚、留白有节奏、对齐严格。
2. **有个性而不花哨**：16 套模板各有明确气质和适用人群，装饰永远退在文字后面，打印出来依然干净。
3. **改设计像调相机**：字号、行距、配色、页头等调整即时可见，任何一步都能撤回；调错了能一键“恢复模板默认”。
4. **所见即所得**：屏幕上看到的分页、断行、颜色，就是 PDF 里的样子。
5. **保留用户喜欢的编辑方式**：对话 + 引导卡片 + 模块编辑的流程不变，变化只发生在右侧预览和“设计 / 模板”两个面板。

## 2. 简历纸面设计系统

简历纸面是独立于应用界面的视觉系统：它不跟随应用的深浅主题，永远是“纸”。

### 2.1 版心与网格

| 项 | 规格 |
| --- | --- |
| 纸张 | A4 210 × 297mm（Harvard 支持 US Letter） |
| 页边距档位 | 窄 12mm · 标准 16mm · 宽 20mm（上下边距 = 左右 × 0.9） |
| 网格 | 12 栏，栏间距 4mm；双栏模板侧栏取 4 栏（约 58–66mm） |
| 基线 | 正文行高的整数倍对齐板块间距（板块间距 = 1.6 × 行高，条目间距 = 0.75 × 行高） |

### 2.2 字号阶梯（pt）

| 档位 | 正文 | 次要信息 | 条目标题 | 板块标题 | 姓名 |
| --- | --- | --- | --- | --- | --- |
| XS | 8.75 | 8 | 9.5 | 10.5 | 由模板定 |
| S | 9.25 | 8.25 | 10 | 11 | 由模板定 |
| **M（默认）** | 9.75 | 8.75 | 10.5 | 11.5 | 由模板定（20–32） |
| L | 10.25 | 9.25 | 11 | 12 | 由模板定 |
| XL | 10.75 | 9.75 | 11.5 | 12.5 | 由模板定 |

- 行高：紧凑 1.42 · 标准 1.55 · 舒展 1.68。
- 数字一律使用等宽数字（`font-variant-numeric: tabular-nums`），日期列右对齐。
- 中文正文不使用斜体；英文副标题可用斜体。
- 标点挤压：开启 `text-spacing-trim`（支持的浏览器）；中英之间不手动加空格，由 `text-autospace` 处理（不支持时保持原样）。

### 2.3 颜色规则

- 正文墨色在纸色上对比度 ≥ 7:1；次要文字 ≥ 4.5:1；强调色用于文字时 ≥ 4.5:1。
- 强调色在一页中出现的位置不超过 3 类（如：板块标题、时间轴圆点、链接）。
- 装饰素材（纸纹、水墨、水彩、线描）透明度上限：纸纹 100%（本身极淡），其余 ≤ 40%，且不得与正文区域重叠超过 15% 面积。
- 黑白打印友好：所有信息不依赖颜色区分（熟练度用点数而非颜色深浅）。

### 2.4 字体组合

| 组合 | 姓名 / 标题 | 正文 | 气质 |
| --- | --- | --- | --- |
| 现代 `sans` | Inter + Noto Sans SC 600/700 | Inter + Noto Sans SC 400 | 清晰、现代 |
| 经典 `serif` | Source Serif 4 + Noto Serif SC 600 | Source Serif 4 + Noto Serif SC 400 | 稳重、学术、国风 |
| 编辑 `mixed` | Source Serif 4 + Noto Serif SC 600 | Inter + Noto Sans SC 400 | 杂志感、设计感 |
| 技术 `tech` | Inter + Noto Sans SC 700 | Inter + Noto Sans SC 400，日期与标签用 JetBrains Mono | 工程师 |

### 3.5 共同规则

- **日期**：条目日期在右侧（时间轴模板在左侧日期列），等宽数字，格式由用户选择（2024.03 · 2024年03月 · 03/2024 · Mar 2024）。
- **要点**：项目与经历的要点使用 3pt 实心圆点（Harvard / 投行用短横线），悬挂缩进；首行与标题对齐。
- **技能**：默认“分类：技能、技能、技能”分组行；子午 / 校园 / 撞色可切换为标签样式；不提供进度条式“熟练度百分比”（不专业、ATS 无法读取）。
- **照片**：只在清单声明“可选”的模板出现；用户可选圆形 / 圆角 / 方形；未上传照片时不留空位、不显示任何占位符号。
- **续页**：第二页起顶部显示“姓名 · 第 2 页”的细页眉；页码在页脚右下角，小号次要色。
- **空内容**：没有内容的板块不渲染；工作台中在预览里以虚线框提示“点击添加”（仅屏幕预览，不进入 PDF）。

## 4. 模板中心

### 4.1 布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 简历模板                                      [我的简历]      │
│ 16 套专业版式，所见即所得导出 PDF                              │
│ [全部] [稳健] [现代] [设计感] [行业]   □仅单页 □支持照片 □英文 │
├──────────────────────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐                  │
│ │ 缩略图 │ │ 缩略图 │ │        │ │        │  每卡：实时渲染   │
│ │        │ │        │ │        │ │        │  第一页（示例内容）│
│ ├────────┤ ├────────┤ ...                                    │
│ │子午 推荐│ │时间轴   │                                       │
│ │●●●● 配色│ │●●● 配色 │  色点可直接切换缩略图配色            │
│ └────────┘ └────────┘                                        │
└──────────────────────────────────────────────────────────────┘
```

- 缩略图使用真实渲染（示例内容为一份完整的中文简历；Harvard 用英文示例），进入视口才渲染，渲染前显示纸张骨架。
- 卡片悬停：缩略图上浮 2px、阴影加深；出现“预览”和“用此模板创建”两个按钮。
- 点击卡片打开**大图预览抽屉**：左侧完整两页预览（可切换配色、字体组合），右侧显示适合人群、特点、支持的调整项和“用此模板创建 / 应用到当前简历”。
- Word 模板目录保留为第二个页签，文案明确“Word 文件需在 Word / WPS 中编辑”。

### 4.2 空态与加载

- 加载：16 张纸张骨架（与卡片同尺寸），淡入替换。
- 筛选无结果：插画 + “没有同时满足这些条件的模板” + “清除筛选”。

## 5. 工作台：预览与设计

### 5.1 预览区

- 纸张以真实尺寸排版后缩放；顶部工具条：缩放（适应宽度 / 75% / 100%）、页数指示“第 1 / 2 页”、溢出提示、当前模板与配色。
- 点击纸面上的板块 → 左侧切换到对应模块编辑（一期行为保留）；悬停时板块出现淡色描边与“编辑”标签（仅屏幕）。
- 溢出提示：`超出 2 页 · 约 18mm`，提供“一键紧凑”和“查看溢出位置”（滚动到第一处溢出并闪烁该板块）。
- 内容更新时纸面不闪烁：新分页结果计算完成后一次性替换。

### 5.2 模板面板

- 顶部分类分段控件；网格两列缩略图，用的是**用户自己的内容**实时渲染（不是示例）。
- 当前模板带“使用中”标记；切换模板时保留内容与通用设置（字号、行距、日期格式、板块顺序），模板专属设置（配色、页头样式）使用新模板默认值；提供“撤销切换”的 toast 按钮（10 秒）。

### 5.3 设计面板

分为四组，每组可折叠：

| 组 | 控件 |
| --- | --- |
| 配色 | 预置配色色板（含名称提示）；自定义强调色（取色器 + 十六进制输入），低对比度时显示“已为可读性调整为 #xxxxxx” |
| 排版 | 字体组合（卡片式，显示“永 Aa”字样）；字号 5 档滑块；行距 3 档；段落间距 3 档；页边距 3 档；目标页数（自动 / 1 页 / 2 页） |
| 页头与细节 | 页头样式（模板允许的变体，以小缩略图展示）；照片（自动 / 显示 / 隐藏 + 形状）；联系方式图标开关；日期格式；装饰素材开关（纸纹 / 水墨等） |
| 板块 | 可拖拽列表（一期 `useSortableList`）：排序、显示 / 隐藏、重命名标题（行内编辑，≤ 16 字）、双栏模板中“移到侧栏 / 主栏” |

- 所有改动即时预览、自动保存（一期设计保存队列）；面板底部“恢复模板默认”。
- 滑块与分段控件都支持键盘；数值变化有 120ms 的预览去抖，避免拖动时频繁重排。

### 5.4 导出对话框

- 顶部显示**服务端渲染的第一页缩略图**（异步，通常 1 秒内出现）与“共 2 页”。
- 检查清单：联系方式是否齐全、是否有空板块、页数是否超出、照片是否适合投递目标（外企提示不建议放照片）。
- 导出完成：显示文件大小、页数、“文字可被招聘系统读取 ✓”（来自 ATS 检查），提供下载与“复制分享链接”（后续）。

## 6. 视觉素材

### 6.1 简历装饰（打印用）

| 素材 | 来源 | 用于 | 规格 |
| --- | --- | --- | --- |
| 象牙 / 冷白 / 亚麻纸纹 | AI 生成，经均匀度校验 | 纸本 | WebP，1240 × 1754，平铺拉伸满版 |
| 远山、竹、梅枝、墨带 | AI 生成，透明背景 | 水墨 | WebP 带透明，透明度 30–40% |
| 靛青 / 鼠尾草 / 赤陶水彩带 | AI 生成，透明背景 | 水彩 | WebP 带透明，裁切顶部 40% |
| 等高线 | AI 生成，透明背景 | 等高线 | WebP 带透明，透明度 28% |
| 极光光晕 | AI 生成，透明背景 | 极光 | WebP 带透明，透明度 55% |
| 网格、点阵、圆点、方印 | 手写 SVG | 多个模板 | 内联 SVG，矢量 |

素材校验流程（每张必须通过）：

1. 透明素材：Alpha 通道透明像素 ≥ 45%，且正文区域（版心中部 60%）覆盖率 ≤ 15%。
2. 纸纹：6 倍对比度拉伸后无暗角、无污渍、无重复图案接缝；四角与中心亮度差 ≤ 2。
3. 打印检查：叠加在示例简历上导出 PDF，在 100% 与 200% 缩放下检查边缘无光晕、无锯齿。
4. 无文字、无签名、无水印、无可识别的版权元素。

### 6.2 应用界面插画

模板中心头图与设计面板引导图沿用一期黏土风格（靛蓝 / 杏橙 / 奶油纸色），新增：模板中心头图“展开的几张简历纸”、设计面板空态“调色盘与纸张”。

## 7. 动效

| 场景 | 动效 |
| --- | --- |
| 切换模板 / 配色 | 纸面交叉淡化 160ms（新排版就绪后才开始） |
| 设计调整 | 无过渡（即时），避免“变形”带来的不确定感 |
| 溢出提示出现 | 自上滑入 180ms；“查看溢出位置”时目标板块描边闪烁两次 |
| 缩略图进入视口 | 骨架 → 内容淡入 200ms |
| 减少动效偏好 | 全部改为无过渡 |

## 8. 可访问性

- 纸面不做成图片（不加 `role="img"`）：保留真实文字结构，屏幕阅读器可以直接阅读简历内容；每页有 `aria-label="简历第 1 页，共 2 页"`。
- 设计面板控件全部有可见标签与键盘操作；色板按钮带颜色名称（“雾蓝”）。
- 导出的 PDF 为带标签 PDF，含文档标题与语言。

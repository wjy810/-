## 1. 背景与目标

求职者在 JobProof 里花最多时间的地方是 AI 简历工作台，而简历最终以 PDF 的形式离开产品。一期的工作台交互获得了认可，但最后一步——**简历长什么样、导出来是不是和屏幕上一样**——仍是演示水平。

二期目标：

1. 用户能从 16 套真正专业的模板中挑选，并细致调整外观；
2. 屏幕所见即导出所得，导出的文件能被招聘系统正确读取；
3. 产品中不再出现编造的数据、假的进度、无效的按钮。

### 1.1 用户与场景

| 用户 | 场景 | 期望 |
| --- | --- | --- |
| 应届生小林 | 校招季要同时投 20 家，部分走网申 | 一份校招风格的简历 + 一份 ATS 友好版本，一键切换 |
| 3 年经验的运营 | 跳槽，希望简历有设计感但不花哨 | 现代版式、带照片、颜色可以换成自己喜欢的 |
| 投行申请者 | 必须严格一页、高密度 | 一键紧凑；明确知道超了多少 |
| 申请海外岗位的工程师 | 需要英文简历 | 英文规范模板，US Letter 纸张 |
| 所有用户 | 导出后发给 HR | 文件和预览一模一样，链接可以点开 |

## 2. 功能需求

### 2.1 模板目录（TPL）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| TPL-01 | 提供 16 套内置模板，分为稳健 / 现代 / 设计感 / 行业四类，每套 2–4 个预置配色（规格见 UI/UX §3） | P0 |
| TPL-02 | 模板中心以**真实渲染**的缩略图展示模板第一页，可直接在卡片上切换配色 | P0 |
| TPL-03 | 按分类、单页 / 多页、支持照片、英文筛选，结果即时更新，筛选条件写入 URL | P1 |
| TPL-04 | 模板大图预览：两页完整预览、切换配色与字体组合、展示适合人群与可调整项 | P1 |
| TPL-05 | “用此模板创建”新建 AI 简历；已有简历可“应用到当前简历” | P0 |
| TPL-06 | 生产环境无需任何演示开关即可使用全部内置模板 | P0 |
| TPL-07 | 运营后台可对内置模板上下架、调整排序与“推荐”标记；不能修改版式 | P1 |
| TPL-08 | 旧模板下线后，使用旧模板的简历自动切换到对应的新模板，内容与通用设置保留 | P0 |

### 2.2 预览与排版（RND）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| RND-01 | 工作台预览与导出 PDF 使用同一渲染器、同一字体；分页、断行、颜色一致 | P0 |
| RND-02 | 页数由实际排版测量得出；超过目标页数时提示超出的高度和第一处溢出的板块 | P0 |
| RND-03 | “一键紧凑”：依次收紧段落间距、行距、字号、页边距直到放得下（最多 4 步），每步可撤销 | P1 |
| RND-04 | 点击预览中的板块跳到对应模块编辑（一期行为保留） | P0 |
| RND-05 | 内容变化后 200ms 内完成重排；输入过程中纸面不闪烁 | P0 |
| RND-06 | 双栏模板中，侧栏与主栏各自跨页；第二页起显示续页眉与页码 | P0 |
| RND-07 | 描述写成多行时自动排成要点列表；支持 `**加粗**` | P1 |
| RND-08 | 个人链接在 PDF 中可点击；只接受 http(s) 链接 | P1 |
| RND-09 | 没有内容的板块不进入 PDF；工作台预览中可显示“点击添加”的占位（仅屏幕） | P1 |
| RND-10 | 简历上不出现任何产品标记或水印 | P0 |

### 2.3 设计调整（DSN）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| DSN-01 | 配色：模板预置配色 + 自定义强调色；对比度不足时自动调整并告知 | P0 |
| DSN-02 | 排版：字体组合（模板允许的 2–3 种）、字号 5 档、行距 3 档、段落间距 3 档、页边距 3 档、目标页数（自动 / 1 / 2） | P0 |
| DSN-03 | 细节：页头样式、照片显示与形状、联系方式图标、日期格式（4 种）、装饰素材开关 | P1 |
| DSN-04 | 板块：拖拽排序、显示 / 隐藏、重命名标题（≤16 字）、双栏模板中移到另一栏 | P0 |
| DSN-05 | 所有调整即时预览、自动保存；“恢复模板默认” | P0 |
| DSN-06 | 切换模板时保留内容与通用设置，模板专属设置取新模板默认值；10 秒内可撤销切换 | P1 |
| DSN-07 | 旧设计设置（v1）自动转换，用户无感 | P0 |

### 2.4 导出（EXP）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| EXP-01 | 导出 PDF 由服务端渲染，文字可选中、可复制，按阅读顺序提取 | P0 |
| EXP-02 | 导出对话框显示服务端渲染的第一页缩略图与页数 | P1 |
| EXP-03 | 每次导出自动做 ATS 文本检查（姓名、联系方式、板块标题、条目标题可提取），结果在导出完成时展示 | P1 |
| EXP-04 | 页数超出目标时导出失败并说明原因与超出位置 | P0 |
| EXP-05 | 排版服务不可用时任务失败、可重试，不生成与预览不一致的文件 | P0 |
| EXP-06 | 导出记录：最近的导出文件可再次下载（不重复占用额度） | P1 |
| EXP-07 | 历史冻结版本按原样式重新导出 | P0 |

### 2.5 真实性与产品化（HON）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| HON-01 | 页面加载失败必须显示错误原因与重试，不得显示为空态或 0 | P0 |
| HON-02 | 进度条与预计时间只显示服务端真实数据；没有数据时不显示数字 | P0 |
| HON-03 | 没有模型评估时不显示分数；标记“待评估”，模型恢复后可重新评估 | P0 |
| HON-04 | 推荐类结果（相似方向等）只展示有依据的项，并展示依据（共同技能），不展示虚构的百分比 | P0 |
| HON-05 | 所有可点击元素都有真实行为；做不到的功能不显示入口 | P0 |
| HON-06 | 检查清单类界面（冻结前检查等）的每一项都来自真实状态 | P0 |
| HON-07 | 界面文案不出现内部字段名、错误码、ID 片段与开发说明 | P1 |
| HON-08 | AI 授权类选项默认不勾选 | P0 |
| HON-09 | 功能未开放时，入口显示“未开放”说明，而不是点进去才报错 | P1 |
| HON-10 | 隐私政策与用户协议去掉开发说明；运营主体、联系方式、备案号来自配置；正式文本未配置时注册保持关闭 | P0 |
| HON-11 | 模拟面试会话页在浅色与深色主题下所有文字清晰可见 | P0 |
| HON-12 | “我已有简历”可以粘贴原简历文本，由 AI 拆分为待确认的卡片内容 | P1 |
| HON-13 | 工作台内可重命名简历 | P1 |

## 3. 非功能需求

| 编号 | 指标 | 目标 |
| --- | --- | --- |
| NFR-01 | 预览重排耗时（2 页内容，中端笔记本） | P95 ≤ 120ms（不含 120ms 去抖） |
| NFR-02 | 导出 PDF 端到端（提交到可下载） | P95 ≤ 4s；渲染服务单次渲染 P95 ≤ 1.5s |
| NFR-03 | 渲染服务内存 | ≤ 512MB（页面池 2） |
| NFR-04 | 首次打开工作台的字体下载 | ≤ 1.5MB（按需切片），之后走缓存 |
| NFR-05 | PDF 文件大小 | 无装饰模板 ≤ 400KB；含纹理模板 ≤ 1.5MB |
| NFR-06 | 文本对比度 | 简历正文 ≥ 7:1；次要文字与强调色文字 ≥ 4.5:1 |
| NFR-07 | 安全 | 渲染服务仅内网、令牌鉴权、禁止外部请求；用户内容不经 `v-html` 渲染 |
| NFR-08 | 兼容 | Chromium 内核浏览器预览与 PDF 一致；Safari / Firefox 允许个别断行差异，以 PDF 为准并在导出前展示 |

## 4. 不在本轮范围

- 管理员上传自定义 HTML 模板（需要沙箱与审核流程）。
- 与模板版式一致的 Word 文件（DOCX 继续提供 ATS 友好的通用版式，并明确标注）。
- 服务端语音识别与录音回放。
- 离线草稿与冲突合并（B-4）、版本回滚（C-6）、列表分页（X-9）、设计系统 legacy 层清理（X-6）。

这些条目保留在 [重构方案](00-重构方案.md) §3 中，状态为“○ 后续”。

## 5. 验收

| 需求 | 验收方式 |
| --- | --- |
| RND-01、EXP-01 | 渲染回归：每个模板 × 配色 × 4 份示例，比较预览截图与 PDF 第一页渲染图；`pdffonts` 为 CID TrueType；`pdftotext` 字段齐全且顺序正确 |
| RND-02、EXP-04 | 超长示例在“目标 1 页”下：预览提示超出；导出失败原因 `RESUME_PAGE_LIMIT_EXCEEDED` |
| TPL-06 | 以 `prod` 配置启动（演示开关关闭），模板接口返回 16 套已发布模板 |
| TPL-08、DSN-07 | 迁移测试：旧模板简历切换到映射模板，设计设置转换后通过 v2 校验 |
| HON-01 | 组件测试：接口失败时页面出现错误与重试按钮，不出现空态文案 |
| HON-03 | 后端测试：AI 不可用时答案 `scores` 为空、状态“待评估” |
| HON-11 | 截图对比 + 对比度计算（浅色 / 深色） |

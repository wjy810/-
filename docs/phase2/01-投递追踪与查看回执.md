# 投递追踪与简历查看回执

> 状态：第一版已上线（V73）。本文记录要解决的问题、产品形态、数据与隐私边界，以及后续的盈利设计。

## 1. 要解决的问题

求职者把简历投出去以后，最大的焦虑是“石沉大海”：不知道对方有没有看、看了多久，也不知道该不该跟进。现有招聘平台只在自己的站内显示“已读”，邮件投递、内推、校招宣讲会、猎头渠道则完全没有反馈。

JobProof 已经有“冻结版本”（导出 PDF 时自动生成的不可变快照）。在它之上，可以给**每家公司一条专属简历链接**：对方点开时，求职者立刻知道。

## 2. 产品形态

| 能力 | 说明 |
| --- | --- |
| 投递看板 | 想投 → 已投递 → 笔试/测评 → 面试中 → Offer → 已结束（接受、婉拒、未通过、主动放弃、没有回应）；拖拽移动，手机上在详情里切换 |
| 专属简历链接 | 记录投递时选择冻结的简历版本即可生成 `/r/{token}`；可隐藏手机号、邮箱和照片；可设 7/30/90 天或长期有效；随时撤回或换新链接（旧链接立即失效） |
| 查看回执 | 打开次数、读者人数（区分转发给了新的人）、每次打开的设备与应用（微信、企业微信、钉钉、飞书、QQ、浏览器）、来源域名、页面可见时长 |
| 提醒 | 首次打开、出现新的读者（可能被转给面试官）时发站内通知，直达这条投递 |
| 漏斗 | 已投递 → 简历被打开 → 进入面试 → 拿到 Offer，每一步相对上一步的转化率；“最远到达的阶段”单独记录，结束的投递仍计入它走到过的阶段 |
| 下一步 | 每条投递可记下一步和时间，看板按最近的下一步排序，逾期标红 |
| 关联 | 可关联岗位匹配（显示匹配分）、所用简历版本；岗位匹配报告页可“记录投递”带入公司与岗位 |

公开页对访客：不需要登录、不被搜索引擎收录（`X-Robots-Tag` 与 `meta robots`），页脚明确说明记录了什么、不记录什么；可“打印 / 存为 PDF”；底部附“也在找工作？”入口——每一次分享都是一次自然曝光。

## 3. 数据与隐私边界

- **不保存访客 IP**：只保存 `sha256(链接 ID | 地址 | User-Agent)`，用于区分“同一个人刷新”和“新的读者”，无法反推地址，且换一条链接就无法关联。
- **不计入的访问**：求职者自己打开（会话识别，页面提示“不会计入回执”）、搜索引擎与链接预览抓取（User-Agent 识别）、同一访客 30 分钟内的刷新（视为同一次阅读）。每条链接每小时最多记录 120 次，防止刷量。
- **阅读时长**：只统计页面处于可见状态的秒数，单次上限 30 分钟；页面关闭时用 `sendBeacon` 补发。心跳必须携带打开时下发的随机密钥（库里只存其哈希），只增不减。
- **数据权利**：投递、时间线、链接与回执纳入账号导出；注销账号时全部删除，链接立即失效；单条投递删除时连同链接与回执一起删除。
- 链接令牌为 128 位随机值。令牌以明文保存，是为了让求职者随时再次复制链接；它只授权读取这一份冻结版本，不授权任何账号操作。

## 4. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/job-applications` | 看板数据与漏斗统计 |
| GET | `/api/v1/job-applications/resume-versions` | 可分享的冻结版本 |
| GET / POST / PUT / DELETE | `/api/v1/job-applications/{id}` | 详情（含时间线、链接、回执）/ 新建 / 编辑 / 删除 |
| POST | `/api/v1/job-applications/{id}/stage` | 移动阶段（结束时必须给出结果） |
| GET / POST | `/api/v1/resume-links` | 链接列表 / 新建 |
| POST | `/api/v1/resume-links/{id}/revoke` | 撤回 |
| GET | `/api/v1/public/resume-links/{token}` | 公开：读取简历 |
| POST | `/api/v1/public/resume-links/{token}/views` | 公开：开始一次阅读 |
| POST | `/api/v1/public/resume-links/{token}/views/{viewId}/heartbeat` | 公开：上报可见时长 |

旧的投递模块（V4，`/api/v1/applications`）已在 V25 下线，其数据作为只读历史保留在资料库里；新模块使用独立的表与路径，互不影响。

## 5. 盈利设计（规划）

| | 免费版 | 专业版 |
| --- | --- | --- |
| 投递记录 | 不限 | 不限 |
| 同时有效的专属链接 | 3 条 | 不限（系统上限 20 → 按套餐放开） |
| 回执 | 打开次数与时间 | 另含读者数、设备与应用、阅读时长、转发提醒 |
| 链接设置 | 长期有效 | 自定义有效期、隐藏联系方式 |

渠道：个人订阅；高校就业中心与培训机构批量采购兑换码（B2B2C）。

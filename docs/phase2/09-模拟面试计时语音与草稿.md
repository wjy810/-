# 模拟面试：计时、语音、压力追问与草稿

> 状态：已上线（V82）。接着 [08](08-模拟面试追问与真实模型检查.md)，修复审查中发现的五处名不副实。

## 1. 计时只算真正在面试的时间

**改之前**：只有点“暂停”、答完最后一题、提前结束或放弃时计时才停。切到别的标签页、点返回、关掉页面，计时都继续走；隔天回来显示几十个小时，报告里的“用时”也失真。设定的 15/30/45/60 分钟只是让时钟变红。

**现在**：
- **切走就暂停**：页面隐藏（切标签页、最小化、锁屏）会自动暂停。回来时看到“已暂停”，并说明原因。
- **离开就暂停**：点返回或跳到别的页面时自动暂停。关闭或刷新标签页时，暂停请求用 `keepalive` 发出，页面卸载后也能送达。
- **心跳**：页面打开并在前台时，每分钟调用一次 `POST /sessions/{id}/heartbeat`，服务端据此更新 `last_active_at`。作答、保存草稿、提交和恢复也会更新它。
- **兜底**：计时在走，但超过 3 分钟（`IDLE_LIMIT`）没有任何活动时（浏览器崩溃、断网、设备休眠），下次读取这场面试时自动暂停，用时只算到最后一次活动。列表里的用时同样算到那一刻。
- **自动暂停后再答题**：提交回答会让计时重新开始。
- **到时提醒**：用时到达设定时长时弹窗一次，可以“结束并生成报告”或“继续作答”。选了继续，本标签页不再提醒。

## 2. 语音模式如实

- **宣传如实**：面试官用浏览器语音读题；你口述作答，浏览器在本机转成文字，提交的是文字。录音不上传、不保存，反馈是文字。首页、创建页和设备检测里原来写的“录音分片上传”“语音反馈”都已改正。
- **不支持转写时不开始录音**：当前浏览器没有语音识别（Chrome、Edge 可以）时：
  - 设备检测会显示“不支持”，并提供“改为文字模拟”；
  - 面试中不开启录音，提示直接输入回答。
  - 以前波形在动，却一个字都不转，录完答案是空的。
- **说清麦克风为什么失败**：分为没有授权、没有设备、被其他应用占用、页面不是 https 四种原因，各自给出对应的处理办法。只有“没有授权”时才显示授权步骤。
- **失败后照样能提交**：麦克风失败后，手动输入的文字可以直接提交；只有正在录音或正在结束转写时才不能提交。以前状态一直停在“失败”，“完成回答”按钮也一直灰着。

## 3. 回答思路的数字校验

上一轮的做法：把回答、简历快照 JSON 和 JD 快照 JSON 拼成一个字符串，再查找子串。快照里有 UUID、版本号、日期，“3”“30”“12”几乎总能找到，编造的“提升 30%”照样能通过。

**现在**：
- **只看用户看得到的文字**：取回答、简历各字段的值、JD 的文字。会跳过 id、`*Id`、版本号、hash、时间戳这类字段，以及 UUID 本身。字段值本身是 JSON 字符串时，先解析再取值。
- **按完整数字比对**：例如 18 不会在 2018 里被找到，8 不会在 18 里被找到。小数末尾的 0 忽略。
- **日期拆开算**：简历里的日期“2019.09”同时支持 2019 和 9。
- 回答思路里出现任何一个找不到出处的数字，就只丢掉这条回答思路，评估照常保留。

## 4. 压力追问名副其实

- **评估输入**：新增 `interviewType`、`thread`（本题此前的原题、回答，以及已问过的追问和回答）和 `followUpRound`。以前评估追问时，只给模型追问本身。
- **压力面试的追问口吻**：直接点出回答里最站不住的一点（证据缺失、数字来源不明、前后矛盾、回避取舍、把团队成果说成个人成果），要求当场给出证据或解释，语气克制但紧追不放。其他类型用平和的口吻追问。
- **追问层层深入**：追问必须在 thread 的基础上再深入一层，不能重复已经问过的问题。
- **出题**：压力面试的题目更尖锐，例如量化并说明数字来源、质疑假设、失败与取舍、资源受限下的决策。
- **基础题库**：删掉了标着“动态追问”的固定题。它在关闭追问时也会出现，压力面试还会把它排到前面。换成一道真正的压力问题：被质疑成果是团队功劳时，怎么说清个人贡献。
- **首页卡片可以点**：首页“按目标练习”的三张卡片现在会直接创建对应类型的面试：行为、专业、压力。

## 5. 草稿能读回

- `GET /drafts/latest`：返回最近 30 天内保存过、还没完成的草稿。创建页会提示“有一份没完成的创建”，并说明岗位、停在第几步、什么时候保存的。
- **继续上次的**：
  - 只恢复认识的字段；已删除的简历或资料会被去掉。
  - 资料授权需要重新确认。
  - 语音草稿退回到设备检测这一步，因为检测结果不保存。
- **重新开始**：调用 `POST /drafts/{id}/discard`，之后不再提示这份草稿。
- **不再堆积空草稿**：每次打开创建页时，如果有一份还没填过的空草稿，就复用它，不再新建。
- **何时不提示**：从岗位匹配或投递追踪带着岗位进来时，不提示旧草稿。

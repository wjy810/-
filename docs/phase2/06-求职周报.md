# 求职周报

> 状态：第一版已上线（V78）。

## 1. 为什么要做

投递是持续一两个月的事，用户很容易忘了回来看。每周一上午一条简短的周报，把“上周发生了什么、这周要做什么”摆在面前：哪些公司打开了简历、这周有哪些面试和笔试。它也是让用户每周回到产品里的固定理由。

## 2. 内容

标题：`求职周报：上周投递 3 家，简历被打开 5 次，进入下一轮 1 次`（只列不为零的项；只有本周安排时为“本周有 N 个安排”）。

正文：

- 上周打开过简历的公司（最多列 3 家，多于 3 家写“等 N 家公司”）；
- 本周（未来 7 天）的笔试、面试等下一步，带时间，最多列 3 项；
- 上周有投递或被打开、但本周没有安排时，提示跟进打开过简历的公司。

点击进入投递追踪。站内与邮件都按“设置 › 通知 › 求职周报”的开关发送（默认都开）。

## 3. 规则

- 统计窗口：北京时间上周一 00:00 至本周一 00:00；“本周安排”从发送时刻起 7 天内、未结束的投递。
- 发送时间：每周一 09:00 之后的第一次扫描（每 5 分钟一次，与日程提醒同一开关 `jobproof.reminders.*`）；服务周一不在线时，周三结束前补发，更晚不再补。
- 只发给有投递记录的求职者，且上周确有内容或本周有安排；什么都没有的不打扰。
- 每个账号每周一条：发送前先在 `weekly_digests` 写入（账号, ISO 周）认领行，多实例不会重复；通知本身也按 `weekly-digest:<周>` 去重。
- 注销账号时删除该账号的认领记录。

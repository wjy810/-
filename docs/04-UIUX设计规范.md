## 1. 旧界面问题诊断

基于 2026-10-06 对旧版本 10 个主要页面的截图走查：

| # | 问题 | 表现 | 影响 |
| --- | --- | --- | --- |
| 1 | 千篇一律的“后台模板感” | 冷灰背景 + 纯蓝主色 + 白卡片，每个页面都是“标题 + 4 个统计卡 + 空列表” | 没有品牌记忆点；对年轻用户缺乏亲和力 |
| 2 | 页面框架不一致 | 资料库顶栏有搜索框和头像，简历页只有铃铛；有的页面标题区带说明、有的带操作，间距各不相同 | 用户每进一个页面都要重新适应 |
| 3 | 空状态敷衍 | 一个灰色线框图标 + “此分类下还没有简历” | 新用户第一眼看到的是“什么都没有”，不知道下一步 |
| 4 | 数据卡片喧宾夺主 | 新用户的工作台满屏“0”“0%” | 传递挫败感，而不是行动方向 |
| 5 | 内部值泄露 | 简历预览副标题显示 `NO_PHOTO` | 显得粗糙不可信 |
| 6 | 交互反馈不足 | 页面切换整页闪白；按钮无按压反馈；列表增删无过渡 | 操作“生硬”，缺少流畅感 |
| 7 | 层级扁平 | 阴影、圆角、边框混用且缺少规律，卡片与背景对比弱 | 信息分组不清 |
| 8 | 未完成功能外露 | “智能编辑 建设中”标签与施工插图 | 降低信任 |
| 9 | 无深色模式、无快捷键 | — | 夜间使用刺眼；熟练用户效率低 |

## 2. 设计理念：纸与墨

> 简历是一张纸，证据是落在纸上的墨。

JobProof 的视觉语言取材于**温润的纸张**与**沉静的墨蓝**：界面像一张整洁的书桌，内容像排版考究的文档；AI 的出现像一束**杏色的灵感光**，温暖但克制。

| 关键词 | 含义 | 落地方式 |
| --- | --- | --- |
| **温暖可信** | 面向焦虑的求职者，界面要让人安心 | 暖调纸白底色、柔和阴影、3D 黏土风插画、友好文案 |
| **清晰专注** | 写简历是需要专注的任务 | 克制的色彩、明确的层级、专注布局隐藏无关元素 |
| **灵动克制** | 流畅但不炫技 | 统一的缓动曲线、短时长动效、只在有意义的时刻出现 |

### 2.1 文案语气

- **像一位靠谱的学长 / 学姐**：直接、具体、鼓励，不说空话。
- 用“你”，不用“您”；用动词开头的按钮（“开始写简历”“导出 PDF”）。
- 不暴露内部术语与枚举（如 `NO_PHOTO`、`PENDING`）；必须出现的专业概念第一次出现时用一句话解释（如“冻结版本：投递用的不可修改快照”）。
- 错误提示 = 发生了什么 + 怎么办，例如“网络连接中断，草稿已保存在本机。恢复网络后会自动同步。”
- 数字使用阿拉伯数字与 tabular 字形；时间优先相对表达（“3 分钟前”），超过 7 天显示日期。

## 4. 图形与插画

### 4.1 插画风格

- **3D 黏土风（soft clay）**：圆润体块、柔和棚拍光、轻微漫反射，无描边。
- **配色**：墨蓝（`#5E59E8` 系）、杏色（`#FA8C55` 系）、奶油纸白（`#F6F1EA`）、少量薄荷绿（成功）与淡紫（AI）。
- **构图**：单一物件或小组合，透明底，留足边距；不出现文字、人脸写实细节与品牌标识。
- **用途**：首页主视觉（多个子物件拼合 + 浮动动效）、空状态、工作台模块入口、引导步骤、错误页。
- **规格**：源图 1024–1254px PNG；产物 WebP（质量 82），显示尺寸的 2 倍；单张 ≤ 80KB。
- 生成提示词与源文件保存在 `design/illustrations/`。

### 4.2 背景与质感

| 元素 | 实现 | 用途 |
| --- | --- | --- |
| 纸张颗粒 | SVG `feTurbulence` 噪点，`opacity .035`，叠加于 `bg-app` | 全局底色的纸感 |
| 点阵网格 | `radial-gradient` 1px 点，间距 20px，`opacity .5` | 预览舞台、能力画布背景 |
| 墨晕光斑 | 大尺寸模糊径向渐变（墨蓝 / 杏色，`opacity .18–.28`） | 首页主视觉、工作台欢迎区 |
| AI 流光 | `--gradient-ai` 沿描边或底部缓慢平移（4s 循环） | AI 生成中的卡片、按钮 |

### 4.3 图标

- 通用图标：Lucide，描边 1.75，尺寸 16 / 18 / 20，颜色继承 `currentColor`。
- 业务图标：沿用 `design/icon-library` 的自有 SVG 图标库（导航与模块入口）。
- 图标按钮必须提供 `aria-label`；与文字并排时间距 6–8px。

## 5. 布局规范

### 5.1 应用外壳（AppLayout）

```text
┌────────────┬──────────────────────────────────────────────────┐
│            │ 顶栏 56px：页面标题 / 面包屑 · ⌘K 搜索 · 通知 · 主题 · 头像 │
│  侧边栏     ├──────────────────────────────────────────────────┤
│  240px     │                                                  │
│ （可折叠为   │   内容区：最大宽 1200，左右边距 24–40              │
│   72px）    │   页面头部 → 主体                                 │
│            │                                                  │
└────────────┴──────────────────────────────────────────────────┘
```

- 侧边栏：顶部品牌标识；导航分组（主要 / 资料 / 系统 / 管理），组间 20px；选中项为 `color-primary-soft` 底 + `color-primary-text` 文字 + 左侧 3px 指示条（带滑动过渡）；底部为“新建简历”主按钮与折叠切换。
- 顶栏：半透明 `surface-1` + `backdrop-filter: blur(12px)`，滚动后出现底部分隔线。
- 背景：`bg-app` + 纸张颗粒。

### 5.2 页面头部（PageHeader）

- 结构：可选的返回 / 面包屑 → 标题（`text-h1`）+ 一句说明（`text-secondary`）→ 右侧操作区（最多 1 个主按钮 + 2 个次按钮）。
- 下方可接分段控件或筛选栏，与头部间距 20px。
- 所有列表 / 总览页使用同一 PageHeader，**禁止**各页自定义标题样式。

### 5.3 页面模式

| 模式 | 用于 | 结构 |
| --- | --- | --- |
| 总览 | 工作台、模拟面试总览 | 欢迎 / 进度区 → 主行动 → 卡片网格 |
| 列表 | 简历、岗位匹配历史、画布、通知 | PageHeader → 分段 / 搜索 / 排序 → 卡片网格或列表 → 空状态 |
| 流程 | 岗位匹配创建、模拟面试创建 | 步骤条（顶部）→ 单列表单卡片（最大宽 760）→ 底部固定操作栏 |
| 详情 / 报告 | 匹配报告、面试报告 | 摘要头部（分数环 + 结论）→ 双栏（主内容 + 侧边目录 / 操作） |
| 专注 | AI 简历工作台、能力画布 | 顶部工具栏 48–56px → 全屏工作区，无侧边栏 |
| 设置 | 账号、外观、AI、数据 | 左侧二级导航（220px）→ 右侧表单分组卡片 |

### 5.4 卡片

- `surface-1` 背景、`border-subtle` 1px 描边、`radius-lg`、`shadow-sm`；内边距 20（紧凑 16）。
- 可点击卡片：悬停 `translateY(-2px)` + `shadow-md` + 描边加深，`dur-base` / `ease-out`；按下 `translateY(0) scale(.99)`。
- 卡片标题 `text-h3`，与正文间距 8；卡片底部操作区与内容间距 16。

## 6. 组件规范

所有组件位于 `frontend/src/shared/ui/`，命名 `Ui*`。下表列出视觉与交互要点。

### 6.1 按钮 UiButton

| 变体 | 外观 | 用途 |
| --- | --- | --- |
| `primary` | `color-primary` 底、白字、`shadow-xs`；悬停加深并上浮 1px | 页面主行动（每个视图最多 1 个） |
| `secondary` | `surface-1` 底、`border-default` 描边 | 次要行动 |
| `soft` | `color-primary-soft` 底、`color-primary-text` 字 | 卡片内行动、筛选激活 |
| `ghost` | 透明，悬停 `surface-3` | 工具栏、低优先级 |
| `danger` | `cinnabar` 底白字 | 不可逆操作的最终确认 |
| `ai` | 白底 + `gradient-ai` 1.5px 渐变描边 + 星光图标 | AI 帮写、AI 推荐、一键优化 |

- 尺寸：`sm` 30px / `md` 36px / `lg` 44px；水平内边距 10 / 14 / 18；圆角 `radius-md`。
- 状态：悬停、按下（`scale(.98)`，`dur-instant`）、焦点（`focus-ring`）、禁用（`opacity .5`，无悬停）、加载（左侧旋转图标替换原图标，文字保留，宽度不跳动）。
- 图标按钮 `UiIconButton`：正方形，尺寸同上，必须有 `label`（用作 `aria-label` 与提示）。

## 7. 交互规范

### 7.1 反馈时效

| 时长 | 反馈方式 |
| --- | --- |
| < 100ms | 直接响应（按压态、切换），无需加载提示 |
| 100ms – 1s | 按钮内加载图标 / 局部旋转图标 |
| 1s – 10s | 骨架屏或进度条；保持界面可操作 |
| > 10s | 阶段文字（“正在解析 JD… 正在对照证据…”）+ 进度百分比 + 可离开页面提示，完成后发通知 |

### 7.2 乐观更新与撤销

- 归档、标记已读、切换模板、卡片排序等低风险操作采用乐观更新，失败时回滚并 toast 说明。
- 归档类操作提供 5 秒“撤销”；撤销优先于二次确认。
- 真正不可逆的操作（删除账号、清除 AI 历史）使用 `UiConfirm` + 危险按钮，必要时要求输入确认文字。

### 7.3 保存状态

工作台、资料库等自动保存场景，在顶栏或卡片右上角统一显示：

| 状态 | 显示 |
| --- | --- |
| 待保存 | 灰点 + “待保存” |
| 保存中 | 旋转图标 + “保存中…” |
| 已保存 | 绿色对勾 + “已保存”（2s 后淡化为时间“刚刚保存”） |
| 失败 | 红色感叹号 + “保存失败 · 重试”（可点击） |
| 离线 | 云朵斜线 + “离线，已保存在本机” |

### 7.4 键盘与快捷键

| 快捷键 | 作用 | 范围 |
| --- | --- | --- |
| ⌘/Ctrl + K | 打开命令面板 | 全局 |
| ? | 快捷键帮助 | 全局（非输入状态） |
| G 然后 D / R / M / P / I | 跳转工作台 / 简历 / 匹配 / 规划 / 面试 | 全局（非输入状态） |
| ⌘/Ctrl + Enter | 确认当前卡片 | 工作台 |
| ⌘/Ctrl + S | 立即保存草稿 | 工作台、资料库 |
| ⌘/Ctrl + / | 聚焦对话输入框 | 工作台 |
| ⌘/Ctrl + E | 打开导出对话框 | 工作台 |
| 1 / 2 / 3 / 4（⌥ + 数字） | 切换对话 / 编辑 / 设计 / 模板视图 | 工作台 |
| Esc | 关闭弹层 / 抽屉 / 命令面板 | 全局 |

- 快捷键在按钮提示中以 `UiKbd` 展示；Windows 显示 Ctrl，macOS 显示 ⌘。
- 焦点顺序符合视觉顺序；所有弹层打开后焦点进入，关闭后回到触发元素。

### 7.5 滚动

- 可滚动区域顶部 / 底部在有更多内容时显示 16px 渐隐遮罩（提示可滚动）。
- 对话流新消息自动滚到底部；用户向上浏览时不打断，并显示“回到底部”浮动按钮。
- 长页面切换路由时滚动回顶；返回时恢复之前的位置。

### 7.6 拖拽

- 拖拽手柄（六点图标）悬停时出现；拖动中原位置显示 `color-primary-soft` 虚线占位，被拖元素 `shadow-lg` + 轻微旋转 1°。
- 放下后其他元素以 `dur-base` 平移到位（FLIP）。
- 始终保留键盘可达的上移 / 下移按钮。

## 8. 动效目录

| 场景 | 动效 | 时长 / 缓动 |
| --- | --- | --- |
| 路由切换 | 内容区交叉淡入 + 新页面 `translateY(6px→0)`（View Transitions，不支持时用 `<Transition>`） | 220ms / standard |
| 列表首次出现 | 卡片依次淡入上浮，间隔 30ms，最多 8 个后同时出现 | 320ms / out |
| 列表增删 | 新项淡入展开；移除项淡出收起；其余项 FLIP 平移 | 220ms / standard |
| 卡片悬停 | 上浮 2px + 阴影加深 | 220ms / out |
| 按钮按下 | `scale(.98)` | 80ms |
| 对话框 / 抽屉 | 见 §6.4 | 320ms / out，退出 200ms / in |
| Toast | 自右滑入 + 淡入；堆叠时下方项缩小 | 由 vue-sonner 提供 |
| 骨架屏 | 高光扫过 | 1.4s 线性循环 |
| 成功勾选 | 圆环描边绘制 + 对勾绘制 | 360ms / spring |
| AI 生成中 | 卡片描边 AI 渐变流动 + 三点跳动 / 文字流式光标闪烁 | 1.2–4s 循环 |
| 简历预览“落版” | 卡片确认后，预览中对应模块背景以 `apricot-50` 高亮后淡出 | 900ms / out |
| 定位高亮 | 点击预览定位到表单字段时，字段描边闪烁一次 `color-primary` | 600ms |
| 首页插画 | 各子物件以不同相位上下浮动 6–10px；鼠标移动时轻微视差 | 5–8s 正弦循环 |
| 数字变化 | 分数、进度数字从旧值滚动到新值 | 600ms / out |

**减少动效**：当用户系统开启“减少动态效果”或在设置中开启时，所有位移与缩放动画替换为纯透明度过渡（≤ 120ms），循环动画全部停止。

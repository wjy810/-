- 模板切换和卡片确认保留未保存编辑；设计、面试文字/语音草稿串行保存，迟到响应不覆盖新修订，409/离页保留恢复副本，导出与提交等待保存排空。
- T15 已收拢为 `shared/lib/draftSaveQueue.ts`，设计和面试两个调用方共享防抖、串行队列、身份/修订判断、恢复备份比较删除及离页保护；冲突后停止待执行定时重试，保留本地副本。新增 13 项共享行为回归。
- 资料主档、记录、排序和面试答案采用 SQL 原子版本条件；并发首次创建主档已有回归，避免静默覆盖。
- 重复生成请求未获执行权时不插入污染原请求的助手失败消息；资料引用数改为聚合查询，移除逐记录查询。
- 离页后才获得的麦克风流立即停止；面试汇总保留有效零分，不批量重写历史报告。SSE 时间与默认模板测试已校正，校园新锐仍是默认模板。
- 后续页面复核修复面试与岗位匹配总览把 0 分显示为缺失的遗漏；页面级测试先复现两项失败，修复后覆盖 0、正常分数、缺失分数共 6 项。
- 生产源码移除内嵌供应商凭据和开发探针；可信代理解析、账号/IP 登录频控、失败审计、未知账号 BCrypt 等时计算及生产 Secure Cookie 已实现并回归。扫描范围与历史密钥边界见 [依赖安全记录](../dependency-security.md)。
- PDF 导出隔离失效 SSE 订阅者：`AiResumeSseService.completeQuietly` 仅处理容器已经结束异步请求时的 `IllegalStateException`，一个断线客户端不再中断正常导出；红绿回归验证其他订阅者仍接收事件。
- 对已提交异步响应，Tomcat 可能以 INCLUDE 调用错误页。新增回归在修复前得到错误的 401；仅允许内部指向 `/error` 且具备容器错误状态属性的 INCLUDE 后保留原响应，直接访问、普通 INCLUDE 和伪造请求头仍不得绕过认证。源码：`SecurityConfig.java`，测试：`AuthSecurityIT.java`。
- 备用端口 POST 的 403 来自隔离 CORS 白名单缺项，通过本地启动参数修复，未扩大生产白名单。通用 403 文案不再误称文件原文权限。

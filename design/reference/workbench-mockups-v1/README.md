# JobProof AI 工作台界面图 v1.0

本目录是根据《产品需求文档 v0.6》《系统架构设计文档 v0.6》《技术选型方案 v0.4》整理的界面探索稿，不代表已经冻结的页面、字段、接口或业务状态。

## 统一视觉基线

- 终端：桌面 Web，1440×1024 左右的宽屏工作台。
- 品牌：JobProof AI / 求职证据官。
- 视觉：深蓝侧栏、白色与冷灰内容区、钴蓝主色、青绿色成功、琥珀色提醒、红色仅用于高风险或阻断。
- 交互：页面、弹窗、右侧抽屉、处理中状态和异常状态分别出图。
- 原则：事实与 AI 推断分离；正式事实需用户确认；结果可追溯；投递绑定不可变简历快照；不默认自动投递、自动代聊或招聘平台抓取。

## P0A 固定左侧导航

1. 工作台：汇总当前任务、最近岗位、投递、面试、通知和异步任务。
2. 求职画像：管理求职方向、画像事实、现实限制和待确认 AI 候选。
3. 能力证据库：管理项目、作品、课程、证书、反馈及简历引用。
4. 岗位匹配：导入 JD、人工校正、确认岗位版本并查看可解释匹配报告。
5. 简历工作台：管理简历、岗位定制版、证据关联、版本对比和投递快照。
6. 投递管理：通过看板、列表和日历管理投递、笔试、面试、跟进和结果。
7. 面试与复盘：管理面试轮次、提醒、材料、文字记录和待确认复盘建议。
8. 通知中心：查看任务进度、状态提醒、失败原因和授权事件。
9. 设置与数据权利：管理账号安全、授权、数据导出、注销与删除影响确认。

## 阶段边界

`10_未来阶段概念稿` 中的页面均不是 P0A 首发菜单：

- P0B：多岗位推荐、个人漏斗与基础招聘风险增强。
- P1：企业核验、薪资谈判、Offer/合同差异审核、实时面试 Copilot 试点。
- P2：仅在官方接口、平台许可和专项合规评审完成后提供平台同步。

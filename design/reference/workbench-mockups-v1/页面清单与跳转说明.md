# 页面清单与跳转说明

## 00 规范与入口

| 图片 | 场景 | 主要去向 |
| --- | --- | --- |
| 01_登录页.png | 账号登录、隐私说明 | 登录后进入工作台；首次用户进入渐进式画像引导 |
| 02_渐进式画像引导.png | 首次填写求职方向和最少必要信息 | 完成后进入求职画像或工作台 |

## 01 工作台

| 图片 | 场景 | 主要交互 |
| --- | --- | --- |
| 01_求职工作台总览.png | 登录后的首页总览 | 导入 JD、补充证据、创建简历、进入投递或面试 |
| 02_今日待办抽屉.png | 点击“今日待办/待办事项” | 在右侧抽屉查看任务、跳转来源页面、标记完成 |

## 02 求职画像

| 图片 | 场景 | 主要交互 |
| --- | --- | --- |
| 01_画像总览与编辑.png | 查看并编辑正式画像事实 | 保存、查看来源、进入候选确认 |
| 02_AI候选事实确认弹窗.png | 点击待确认 AI 候选 | 确认、更正或拒绝；确认后才写入正式画像 |

## 03 能力证据库

| 图片 | 场景 | 主要交互 |
| --- | --- | --- |
| 01_能力证据列表.png | 查看证据、强度、技能与简历引用 | 新增证据、筛选、打开详情 |
| 02_新增证据弹窗.png | 点击“新增证据” | 选择类型、填写内容、上传材料、保存草稿 |
| 03_证据详情抽屉.png | 点击某条证据 | 查看来源、关联技能、引用版本和历史 |
| 04_删除受阻弹窗.png | 删除被有效简历引用的证据 | 阻止删除，只允许归档或查看引用 |

## 04 岗位匹配

| 图片 | 场景 | 主要交互 |
| --- | --- | --- |
| 01_JD文本导入.png | 粘贴岗位 JD | 保存草稿、开始解析 |
| 02_JD人工校正.png | 解析完成后人工校正 | 确认关键字段、保持未知项 |
| 03_确认岗位版本弹窗.png | 点击“确认岗位版本” | 二次确认关键字段并冻结输入版本 |
| 04_匹配任务处理中.png | 创建异步匹配任务后 | 查看进度、取消允许取消的任务、返回工作台 |
| 05_当前匹配报告.png | 查看可解释匹配结果 | 创建定制简历、记录待投递、补充证据 |
| 06_过期报告与重新计算弹窗.png | 画像/JD/证据变化导致报告过期 | 保留历史报告并创建新任务，不覆盖原报告 |

## 05 简历工作台

| 图片 | 场景 | 主要交互 |
| --- | --- | --- |
| 01_简历列表.png | 查看主简历、定制版和投递快照 | 新建、复制、归档、打开编辑器 |
| 02_简历编辑器.png | 编辑岗位定制简历 | 关联证据、版本对比、导出或冻结投递版本 |
| 03_关联证据抽屉.png | 点击简历描述旁的证据入口 | 选择证据、查看来源、确认关联 |
| 04_版本对比.png | 点击“版本对比” | 查看增删改和证据变化，选择回滚目标 |
| 05_冻结投递版本弹窗.png | 点击“冻结为投递版本” | 校验证据后创建不可变快照 |

## 06 投递管理

| 图片 | 场景 | 主要交互 |
| --- | --- | --- |
| 01_投递看板.png | 按阶段查看投递 | 拖动或更新状态、进入详情 |
| 02_投递列表.png | 按字段批量查看投递 | 搜索、筛选、排序、进入详情 |
| 03_投递日历.png | 查看跟进、笔试、面试和截止时间 | 点击日程进入投递或面试详情 |
| 04_新增投递弹窗.png | 点击“新增投递/记录已投递” | 绑定岗位与不可变简历版本，设置渠道和跟进时间 |
| 05_投递详情抽屉.png | 点击投递卡片或列表行 | 查看时间线、绑定版本、面试和备注 |
| 06_更新阶段弹窗.png | 点击“更新状态” | 选择新阶段、填写时间与原因，留下状态历史 |

## 07 面试与复盘

| 图片 | 场景 | 主要交互 |
| --- | --- | --- |
| 01_面试总览.png | 查看全部待办面试与复盘 | 打开面试、安排轮次、继续复盘 |
| 02_安排面试轮次弹窗.png | 点击“新增轮次/安排面试” | 设置轮次、时间、方式、时区和提醒 |
| 03_面试详情.png | 查看单次投递的轮次和材料 | 编辑安排、导入文字记录、开始复盘 |
| 04_导入文字记录弹窗.png | 点击“导入文字记录” | 粘贴或上传文字，确认授权和保留范围 |
| 05_面试复盘报告.png | 查看 AI 初稿 | 确认、编辑、拒绝建议或加入训练清单 |
| 06_确认弱项候选抽屉.png | 点击待确认弱项 | 确认、更正或拒绝；未确认不写入正式画像 |

| --- | --- | --- |
